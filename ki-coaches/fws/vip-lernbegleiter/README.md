## Pflegehinweise

- Der Prompt steht in `coach.html` **nur einmal**: im `<textarea id="raw">`.
  Die Lesefassung, der kopierte Text und die Textdatei werden daraus beim Öffnen
  der Seite erzeugt. Änderungen also nur dort vornehmen.
- Die drei Platzhalter `[HIER … VON DER THEMENKARTE EINTRAGEN]` müssen im Prompt
  wörtlich so stehen bleiben, sonst werden die Felder der Themenkarte nicht eingesetzt.
- Gegenüber der Vorlage geändert: Die KI fragt nach **Kürzeln** statt nach Vornamen
  (zwei Stellen im Prompt), passend zu den Nutzungshinweisen der KI-Coaches.
- Zeitabhängig: die Ministeriumsbezeichnung (BMBFSFJ, bmbfsfj.bund.de).
- Ohne JavaScript erscheint der Prompt als einfaches Textfeld; die Seite bleibt nutzbar.
